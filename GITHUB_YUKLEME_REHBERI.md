# GitHub'a 2 Dakikada Yükleme Rehberi (Hiç Kod Bilmeden!)

Bu projeyi hazırladık. Bilgisayarında hazır olan bu dosyaları GitHub hesabına yüklemek için en kolay **2 farklı yol** aşağıdadır. Hiçbir program kurmadan **1. Yolu (Web Sitesi Üzerinden)** yapmanı öneririz:

---

## 🚀 1. Yol: Doğrudan GitHub Web Sitesi Üzerinden (En Kolay Yol - 2 Dakika)

1. Tarayıcından [github.com](https://github.com) adresine gir ve hesabına giriş yap (hesabın yoksa ücretsiz 1 dakikada oluştur).
2. Sağ üst köşedeki **"+"** simgesine tıkla ve **"New repository"** (Yeni Depo) seçeneğini seç.
3. Ayarları şu şekilde yap:
   * **Repository name (Proje Adı):** `uniflow-campus-transit` *(veya istediğin herhangi bir isim)*
   * **Public / Private:** **Public** (Açık) seçeneğini işaretle (Jürinin görebilmesi için Public olmalıdır).
   * Aşağıdaki *"Add a README file"* kutucuğunu **işaretleme** (çünkü biz zaten hazırladık).
   * Yeşil **"Create repository"** butonuna bas.
4. Karşına gelen ekranda mavi renkle yazan **"uploading an existing file"** (var olan dosyaları yükleyin) linkine tıkla.
5. Şimdi bilgisayarındaki şu klasörü aç:
   📁 `C:\Users\yakub\.gemini\antigravity\scratch\uniflow-campus-transit`
6. Bu klasörün içindeki şu dosyaların tamamını seç ve GitHub sayfasındaki alana **Sürükle & Bırak (Drag & Drop)**:
   * `index.html`
   * `style.css`
   * `app.js`
   * `README.md`
   * `VIDEO_SCRIPT.md`
   * `GITHUB_YUKLEME_REHBERI.md`
   * `LICENSE`
7. Dosyalar yüklendikten sonra sayfanın altındaki yeşil **"Commit changes"** butonuna bas!
8. **Tebrikler!** Projen GitHub'da harika bir şekilde yayınlandı. Sayfayı açtığında hazırladığımız profesyonel `README.md` vitrini doğrudan görünecektir.

---

## 🌐 Bonus: Canlı Web Sitesi Haline Getirme (GitHub Pages - 30 Saniye)

Jürinin tek tıkla projenin canlı halini tarayıcıda incelemesi için:
1. GitHub reponun üst menüsündeki **"Settings"** (Ayarlar) sekmesine tıkla.
2. Sol menüden **"Pages"** seçeneğine tıkla.
3. **"Branch"** kısmından `main` (veya `master`) dalını seç ve **"Save"** de.
4. Yaklaşık 1 dakika sonra sana bir link verecek (Örn: `https://kullaniciadiniz.github.io/uniflow-campus-transit/`).
5. Bu linki yarışma başvuru formuna "Canlı Demo Linki" olarak ekleyebilirsin!
